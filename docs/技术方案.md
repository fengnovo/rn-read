# RN Read 技术方案
## 产品行为

React Native 本地优先阅读器，默认进入最近列表，四个入口：最近、文件、离线、浏览。支持网页浏览与当前内容保存，Markdown/Mermaid、PDF、目录长期访问、阅读恢复、缩放与存储管理。无需后端和账户。

已保存网页直接读取本地快照；重新访问原网页是独立操作。系统选择的 PDF/Markdown 自动保留持久本地副本，Provider 失效不影响副本。目录引用仍依赖 Provider，不能把长期权限等同于离线可用。目录为空与权限失效需区分。

## 技术栈

Expo SDK 57 / React Native 0.86 / TypeScript / Development Build / New Architecture；确切补丁版本由 package-lock.json 固定，安装后执行 Expo 兼容检查。不使用 Expo Go。

- React Navigation：类型化导航。
- react-native-webview：浏览器、HTML 阅读和图表查看。
- react-native-pdf + react-native-blob-util：原生 PDF、页码/缩放。
- markdown-it：Markdown，关闭输入中的原始 HTML。
- Mermaid、DOMPurify、Mozilla Readability：本地构建 IIFE runtime，包含依赖，不使用 CDN、远程字体或运行时联网 import。
- HTML parser + CSS parser：资源发现和改写，不以全局正则替代语法解析。
- expo-sqlite：版本化 migration，参数化 SQL。
- expo-file-system / expo-asset / expo-crypto：持久文件、运行时物化与哈希。
- @react-native-documents/picker：系统选择；本地 Expo Module：外部目录枚举、bookmark 恢复、流式复制。
- Vitest + 浏览器自动化：核心和真实 Web runtime 验证。

## 模块结构

src/app 管理导航、主题和服务；screens 管理界面；core 管理不依赖 RN 的路径、捕获协议、阅读位置和状态；database 管理索引；services 管理导入、网页保存与缓存；storage 管理文件；web 管理捕获和阅读 runtime。modules/document-access 管理 Android/iOS 权限差异。

Screen 不拼 URI、不直接执行 SQL。Reader 接收已经准备好的应用内文件。

## 文件权限

Android 目录采用 ACTION_OPEN_DOCUMENT_TREE 并保存 persistable grant。通过 DocumentsContract 查询目录子项，以 document ID 定位子文件；不能在 content URI 后拼文件名。使用 ContentResolver 流式复制，禁止把大 PDF 转成 Base64。

iOS 每次操作解析 bookmark，处理 stale 并返回更新后的 bookmark。读取前开启 security scope，通过 NSFileCoordinator 枚举/复制，完成后释放。Reader 只读取已复制的文件，避免异步 PDF 渲染与权限生命周期耦合。

原文件身份以 provider identity 为去重键，首次登记后稳定保存 resourceId。Android 采用 authority + documentId；iOS 优先资源标识。不要每次打开产生新 UUID，也不能仅凭复制后的 URI 判定身份。

Markdown 引用模型包含授权目录、文档相对位置和来源 URI。相对图片和 .md 链接由权限层解析；允许授权根内部 ../，禁止越出根目录、任意 scheme 或绝对系统路径。中文、空格与百分号编码须保留。单独选择文件没有父目录权限时，提示选择所在目录。导入 Markdown 离线副本同时复制相对图片，缺失依赖形成警告。

## 持久存储

SQLite resources：稳定 ID、来源 key、类型、标题、来源 URI、目录 ID、相对位置、本地相对路径、大小、状态、最近时间、阅读位置 JSON。
folders：目录 URI、bookmark、显示名、最近相对子目录。
save_jobs：任务 ID、资源 ID、临时目录、最终目录和 saving 状态。操作错误在当前界面呈现，未提交的副本不进入可读列表。

应用内文件只存相对路径，每次根据当前持久根解析。持久根包含 imported、offline、readers、runtime、staging。缓存清理不能删除用户保存的副本。

保存任务采用 saving；可读资源采用 ready 或 ready_with_warnings，删除中的资源采用 deleting。ready 与 ready_with_warnings 都是可阅读成功终态。

保存：记录任务 → 临时目录写资源/入口/manifest → 校验 → 同一持久根内移动 → SQLite 原子写入索引 → 移除任务。SQLite 与文件系统没有跨介质事务；后台恢复根据 manifest 对账，最终目录完整则补提交，只有临时目录则清理并移除未完成任务。删除先记录 deleting，删除应用管理的目录后删除索引；中断后重试。永不删除原文件。

## 网页离线保存

用户点击保存后抓取当前已加载 DOM。未进入 DOM 的虚拟正文、未加载懒图片、canvas/WebGL、视频和复杂 iframe 不保证保存；界面说明支持边界。提供原样快照与 Readability 阅读模式，正文提取失败时允许改用原样快照。

Capture 使用用户发起的 captureId，按 JS 字符串长度分块，每块最多 128×1024、总长度最多 20×1024×1024（UTF-16 单元），超时 30 秒。落盘页面总大小另按字节限制为 100 MiB。序号、总长度、会话必须校验，导航或取消后丢弃旧消息。

捕获时固定 img.currentSrc 并去掉远程 srcset/source。保存 document.baseURI 用于资源解析；链接按此地址解析，明确指向当前页面的锚点保留为本地片段，其余链接绝对化，再删除 base。资源覆盖图片、样式、字体、内联 CSS、url 和 @import。每个外部 CSS 的相对 URL 以最终响应地址解析；递归去重、防循环，最大深度 8。

并发下载 4，单资源超时 20 秒，页面最大 100 MiB、500 个资源。校验状态码和类型，以 URL 哈希生成安全文件名。失败和 blob 资源形成警告并去掉远程回退，不能保存后继续等待网络。

## 阅读 runtime 与安全

在线浏览器和本地 Reader 分开。本地模板启用 JS，只保留应用自己的 runtime；移除原网页脚本、事件属性、危险 URL、iframe/object/embed、meta refresh、远程 preload/prefetch。Markdown 原始 HTML 关闭；Mermaid 源通过 textContent 写入，固定 strict 配置，单图错误不阻止正文显示。

CSP 阻止联网：connect-src/frame-src/form-action/base-uri 均为 none；资源仅允许必要本地来源。Bridge 只接受校验过的 READY、POSITION、OPEN_LINK、DIAGRAM 消息，不能开放任意文件或命令执行。

采用本地 file URI；iOS allowingReadAccessToURL 限定阅读存储根；Android 仅为应用自己的净化模板启用 allowFileAccess，禁止 allowUniversalAccessFromFileURLs 和 allowFileAccessFromFileURLs。runtime 是完整 IIFE，不依赖 file origin 的 fetch/ESM。资源访问由统一 resolver 管理；设备兼容性需要两端实际验证。

## 自适应、图表、进度

正文 device-width viewport，允许双指缩放；图片 fit width；代码和表格局部横向滚动。Mermaid 正文默认 fit width，点击独立查看器支持缩放、拖动、重置。PDF fitPolicy=0，用 onLayout 测量容器，恢复页码与 scale。

HTML 进度保存段落/标题锚点、相对偏移、百分比和 scrollY。等待图片/字体/图表布局后恢复；恢复期间不得把顶部位置覆盖旧进度。持续阅读节流保存，切后台/退出立即 flush。

默认先完成数据库迁移并展示最近列表。权限检查、清理、存储统计后台执行，点击文件时再验证来源。Markdown HTML 按内容版本、模板与渲染器配置缓存；runtime 保存 SVG 缓存，第二次打开避免重新布局。

最近资源保留 200 项入口；文件与离线库在 SQL 中先筛选类型，再以每页 60 项分页加载，保存资料不因最近列表上限而失去入口。后台恢复完成后自动刷新索引列表。

性能验收目标：中端真机普通本地文档点击到正文首屏 P95≤1秒；冷启动、大 PDF 与复杂图表单独统计。目标不等于已测结果。

## 界面

中文、系统字体、明暗主题、Safe Area、48dp 触控区域、同一矢量图标库，FlatList 列表。加载、取消、空目录、失效权限、缺失图片、图表语法错误、PDF 密码错误、磁盘不足分别展示可操作信息。重导入/重新授权保留资源身份和进度。

## 验收

1. 两端原生依赖编译，记录实际结果。
2. 授权目录，浏览子目录，导入带图片、Mermaid 的 Markdown 与 PDF。
3. 保存公开文章和技术文档，检查资源本地化、失败警告。
4. 阅读后杀进程，断网重启：副本、图表、页码、锚点、最近条目恢复。
5. 来源删除后副本继续读取；引用目录失效可重新授权。
6. 保存/删除中断恢复，磁盘不足和超时不产生假成功。
7. 竖屏、横屏、大字号、缩放与图表拖动可用。
8. 静态检查、纯核心测试、浏览器测试、模拟器测试、真机测试分开报告。未执行项目明确标注。
